This page is intended for **Project Leads, Accessibility Specialists, and Developers** who need to manage issues within external task management software. Downloading scan results into a CSV file allows you to sort blockers and upload them directly into tools like JIRA or Rally to assign remediation tickets to specific team members.
## Downloading files
Downloading the results into a CSV file lets you quickly scan, sort, and manage blockers.
```tip
💡Tip: You can upload this file directly into your task management tool to create "tickets" for every accessibility blocker found. Once in the task management tool, you can assign specific errors to a particular team member for resolution.
```
