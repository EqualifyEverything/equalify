# Technical Support & Open Source

Equalify is an open-source project developed by a community.

## For Developers & Technical Users
If you are technical or want to contribute:
- **GitHub Repository**: You can access the source code at [github.com/equalify-everything/equalify](https://github.com/equalify-everything/equalify).
- **Reporting Issues**:
    1.  Go to the GitHub repository.
    2.  Click **New Issue**.
    3.  Choose **Bug** or **Feature Request**.
    4.  Fill in the template (describe the bug, steps to reproduce, etc.).
    5.  The engineering team monitors these issues.

## General Support
If you are not using GitHub or need general assistance coverage:
- You can email the **Digital Accessibility Team**.
- They are available to help solve issues or answer questions about interpretation of blockers.
