This page is intended for **all users** who want to group and find audits more easily. Tags are short labels, such as a department, website, or project name, that you attach to audits. Once your audits are tagged, you can filter the Audits page to show only the audits you care about.

## How tags work
- **Tags are shared across your workspace.** Any tag you create can be used by everyone in your workspace, and everyone sees the same tags on an audit.
- **An audit can have as many tags as you need**, and a tag can be used on any number of audits.
- **Anyone can create and apply tags.** Renaming, merging, and deleting tags is limited to Admins. See [🔗 "Managing tags"](https://equalify.uic.edu/dashboard/user-guide/5-administration/5-5-managing-tags).
- **Quick scans can't be tagged.** Tags are only available on audits.

## Adding tags to an audit
You can add tags when you create an audit, or at any time afterwards.
- **In the Audit Builder:** Use the **Tags** field in the General Info section, below Scan Frequency. The tags are saved when you save the audit.
- **On an audit's page:** Use the **Tags** field just below the audit name. Changes are saved as soon as you make them.

To add a tag:
1. Click in the **Tags** field and start typing. A list of matching tags appears as you type.
2. Select a tag from the list with your mouse, or use the arrow keys and press Enter.
3. Repeat to add more tags.

## Creating a new tag
If no existing tag matches what you typed, the list offers a **Create tag "…"** option.
1. Type the name of the new tag.
2. Select **Create tag "…"** from the list.
3. A confirmation window appears, reminding you that tags are shared with everyone in your workspace. Select **Create Tag** to confirm, or **Cancel** to go back.

The new tag is added to the audit and becomes available to everyone in your workspace.

```tip
💡Tip: Before creating a tag, check the list for one that already exists. Tag names are not case-sensitive, so typing "library" will find an existing "Library" tag rather than creating a second one.
```
```important
⚠️Important: Tag names can be up to 50 characters long.
```

## Removing a tag from an audit
On the audit's page (or in the Audit Builder), select the **×** next to the tag in the **Tags** field. You can also press Backspace in an empty Tags field to remove the last tag.

Removing a tag from an audit does not delete the tag itself. It stays available for other audits.

## Filtering the Audits page by tag
Once at least one tag exists, a **Filter by Tags** control appears at the top of the Audits page, next to Search and Filter View.
1. Click **Filter by Tags** and choose one or more tags.
2. The page shows only audits that have **any** of the selected tags. For example, choosing "Library" and "Athletics" shows audits tagged Library, audits tagged Athletics, and audits tagged with both.
3. To clear the filter, remove the tags from the control.

The tag filter works together with **Search** and **Filter View** (My Audits or All Audits). Equalify remembers your tag selection the next time you visit the Audits page.

```tip
💡Tip: If no audits match your selection, the page shows a "No audits match the selected tags" message with a **Clear Tag Filter** button.
```

## Where tags appear
- **Audit cards and table:** Tags are shown on each audit card and in the **Tags** column of the table view. To save space, cards show up to three tags and the table shows up to two. When an audit has more, a chip such as **+3** appears. Hover over it, focus it with the keyboard, or select it to see the rest. Screen readers announce it as, for example, "+3 more tags", followed by the names of the hidden tags.
- **Audit page:** All of an audit's tags are shown in the Tags field below the audit name.
- **Shared reports:** People viewing a [🔗 shared report](https://equalify.uic.edu/dashboard/user-guide/3-interpreting-audit-data-and-dashboards/3-5-notifications-reporting-and-sharing) can see the audit's tags, but can't change them.
- **Logs:** Creating tags, and adding or removing tags on an audit, are recorded on the Logs page. See [🔗 "What gets logged"](https://equalify.uic.edu/dashboard/user-guide/4-compliance-and-logs/4-2-what-gets-logged-and-the-importance-of-audit-logs).

## Choosing good tag names
Tags work best when your workspace agrees on a small, consistent set of names.
- **Use names everyone will recognize**, such as department, college, or website names (e.g., "College of Dentistry" or "Athletics").
- **Be consistent.** Pick one form of a name and stick with it. Avoid creating near-duplicates such as "Athletics" and "Sports", or "PDFs" and "PDF Documents".
- **Keep tags short.** Shorter tags are easier to read on audit cards and in the table.
- **Don't repeat what's already tracked.** Like audit names, tags don't need dates or URLs. Equalify records those automatically.

If duplicate tags do appear, an Admin can merge them into one. See [🔗 "Managing tags"](https://equalify.uic.edu/dashboard/user-guide/5-administration/5-5-managing-tags).
