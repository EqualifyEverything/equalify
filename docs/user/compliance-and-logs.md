# Compliance and Logs

Equalify includes a robust logging system to support your compliance efforts.

## The Logs Screen
- Accessed via the main navigation menu.
- **What is logged?** Equalify logs every user action, including:
    - Adding pages
    - Deleting pages
    - Running scans
    - Ignoring blockers

## Why is this important?
- **Proof of Compliance**: The logs serve as an audit trail.
- **Verification**: You can demonstrate over time that you are actively monitoring and addressing accessibility issues.
- **Accountability**: It helps track who made changes to audits or configurations.
