# Getting Started with Equalify

## Logging In
Equalify starts with a login screen. You must log in using an SSO (Single Sign-On) provider.
- If you are a UIC user, you can log in directly with your UIC credentials.

## The Dashboard
Once logged in, you will be taken to the **Audits** screen. This is your home base.
- **Main View**: You will see a list of audits that you and your team have run in the past.
- **Navigation**: The main navigation menu provides access to:
    - **Audits**: Your dashboard.
    - **Logs**: Activity history.
    - **Account**: User settings.

## First Steps
Most users will start by clicking into an existing audit to check the status of their blockers or by creating a new audit to start scanning their content.
