Equalify is an open-source project. You can report technical issues via GitHub or contact the digital accessibility team for support. 

GitHub is where Equalify code is stored, but it's also where we organize features, issues, ideas, and roadmaps. We use labels to organize and structure items, making them easier to find. 

Stay up to date on the latest features by signing up for the [Equalify newsletter.](https://it.uic.edu/accessibility/engineering/)

If you are not using GitHub or need general assistance, you can email the Digital Accessibility Team at [accessibility@UIC.edu](mailto:accessibility@UIC.edu). Email the team to help with: 
- Solve issues
- Answer questions about the interpretation of blockers
- Troubleshooting common errors
- Admin and access problems
- And more, reach out!
